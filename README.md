# InCareReg: Sistema de Regulação em Saúde

> Estudo de caso. O código-fonte é privado e pertence à **RJF Consultoria**. Este repositório apresenta o projeto e a minha participação nele. As imagens usam **dados fictícios**.

## O problema
Na saúde pública, as vagas de consultas especializadas, exames e leitos são limitadas. A **regulação** decide quem é atendido, onde e quando, de acordo com a prioridade clínica e com a capacidade disponível. Sem um sistema, esse controle fica em planilhas e telefonemas, e as filas ficam sem transparência.

## A solução
O **InCareReg** centraliza a regulação do município:
- As unidades de saúde **enviam solicitações** de consultas, exames ou procedimentos
- Os reguladores **avaliam e priorizam** cada pedido
- O sistema faz o **agendamento** e o **encaminhamento** para o serviço disponível
- Todos **acompanham a situação** de cada solicitação
